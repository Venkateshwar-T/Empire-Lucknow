# Moonlight Cafe — Lucknow
### Artisan Coffee, Bakery & Late-Night Sanctuary

> A calm, nocturnal digital experience for **Moonlight Cafe**, located on Riverside Walk, Gomti Nagar, Lucknow. Open daily from 7:00 AM to 2:00 AM.

---

## Design Highlights & Key Features

- **Branding**: Clean, elegant **Moonlight Cafe** typography with celestial crescent glyph.
- **Uncongested, Responsive Navigation**:
  - Desktop: 4 crisp, non-wrapping navigation links (`Brews & Bakery`, `Ambient Nooks`, `Hours & Location`, `Reserve Table`), quick search, and glowing reservation pill.
  - Mobile: Clean header (Wordmark + Search + Hamburger), full-screen animated menu drawer, and 4-icon bottom floating dock (Brews, Nooks, Search, Reserve).
- **Artistic Hero Section (Non-Template CTA Placement)**:
  - Replaced generic stacked buttons with an **Artistic Sanctuary Action Deck**:
    - **Pass 01**: *The Night Brews* interactive tasting flight pass (`→`).
    - **Pass 02**: *Reserve A Nook* table sanctuary pass (`↗`).
  - **Interactive Vinyl Turntable Dock**: Spinning analog record animation (*Bill Evans — Peace Piece*) with tap-to-pause/play interaction.
- **The Curated Menu (Mobile 2-Column Grid)**:
  - **Mobile 2-Column Layout**: High-density, proportional 2-column card grid designed specifically for phone screens.
  - **Zero-Overflow Responsive Filters**: Smooth touch-scrollable category pills (`All Items`, `Espresso`, `Slow Pour`, `Bakery`, `Botanicals`, `Tartines`) that never blow out mobile viewport widths.
  - **Instant Search**: Clean search box with clear button (`✕`) and live item filtering.
  - **Tasting Notes Inspector**: Tap any item to inspect origin, roast, and tasting notes in a glassmorphic modal.
- **The 4 Ambient Nooks**:
  - *01. Vinyl Mezzanine*
  - *02. Glasshouse Solarium*
  - *03. Solo Library*
  - *04. Copper Slow Bar*
  - Clicking any nook smoothly jumps to the reservation form with that nook pre-selected.
- **Intuitive Nook & Table Reservation**:
  - Select nook, date, guest count, and time slots up to 11:30 PM.
  - Instant modal confirmation with voucher reference `#MLC-XXXX`.
- **Riverside Walk Location Card**:
  - Stylized dark vector map of Gomti Nagar with river curves, 300 Mbps fiber notice, and valet parking.
